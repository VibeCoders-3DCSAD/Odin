Budgie Budgie · Personal Budget Management · Mobile · V5
Every component the 61 screens of Budgie-screens-v5.html are built from, drawn at real size with its states. Build one Figma component per card and give it a variant for each state shown. Each card renders through the same renderer, theme and overrides the board uses, so a component here cannot drift from a screen there. The app is Budgie, after the bird, and it keeps the mark it already had.

Seventeen values, down from V4's thirty-eight. Four greens inside 2.8 CIELAB units of each other became one, three mid greys became ink2, and eleven pale tints became four. The card border merged into ink2 as well: anything dark enough for 7:1 against the cream page sits within 5 CIELAB units of it. Every value here clears 7:1 against every surface it prints on, so V4's rule that tone-coloured text sits on white only is retired. The neon green stays fill only — 1.27:1 on the page — and a selected chip now takes a brand edge, because the neon fill alone is 1.51:1 against a card.

Contrast, all 61 pairs

Every pair V5 draws, computed with the WCAG 2.1 relative-luminance formula and held to 7:1. All of them pass. node build/build-v5.js recomputes this list and refuses to write the board if one drops below its threshold, so a palette change cannot ship quietly.
