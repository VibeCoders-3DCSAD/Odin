## 6. Budgeting Module

### 6.1 Retired Budget Drafts

- Existing budget drafts and allocations remain syncable as legacy records.
- The Budget Tracker is removed from the application and legacy drafts are no
  longer presented in the user interface.
- Existing budget allocations are never reinterpreted as Financial Plan
  `Fixed`, `Minimum`, or `Flexible` rules.
- Legacy budget records are not copied, replaced, deleted, or mutated while a
  Financial Plan is generated or accepted.

### 6.2 New Planning

- New monthly planning is created only through the Financial Plan module.
- The Financial Plan is always for the next calendar month and is explicitly
  accepted before it is saved.
- The tracker empty state directs users to Financial Plan. It does not offer a
  manual draft form or a legacy budget recommendation workflow.
